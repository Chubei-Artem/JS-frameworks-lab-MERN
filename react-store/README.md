# React Store — Лабораторна робота №4

Веб-застосунок каталогу електронних товарів з реалізацією повноцінного CRUD-функціоналу, інтерактивного інтерфейсу користувача, збереженням стану в `localStorage`, темною/світлою темами оформлення та розгортанням у хмарі за допомогою Docker.

- **Live Demo (Render) db.json:** [https://js-frameworks-lab-react-1.onrender.com/](https://js-frameworks-lab-react-1.onrender.com/)

## 🛠 Технологічний стек
- **Frontend:** React 18, Vite
- **Стилізація:** Модульний чистий CSS3 (CSS Variables, Flexbox, CSS Grid, Radial Gradient Glow Effect)
- **HTTP-клієнт:** Axios
- **Mock REST API:** `json-server` (`db.json`)
- **Контейнеризація:** Docker (Multi-stage build: Node.js Alpine + Nginx Alpine)
- **Хмарний хостинг:** Render.com

## 📌 Основний функціонал застосунку
1. **CRUD-операції над сутностями (товарами):**
   - **Create (POST):** Додавання нового товару через форму з клієнтською валідацією полів.
   - **Read (GET):** Отримання списку товарів з REST API або автономного локального фолбеку при завантаженні.
   - **Update (PUT):** Редагування назви та ціни товару прямо в картці (inline edit) з обов'язковою валідацією.
   - **Delete (DELETE):** Безпечне видалення товару з каталогу та синхронне видалення його з кошика.
2. **Трекінг сутностей (вимога методички):**
   - Поле `createdAt` — дата додавання товару.
   - Поле `views` — автоматичний лічильник кількості переглядів товару, що інкрементується на бекенді при відкритті деталей.
   - Поле `status` — автоматичне визначення наявності товару (`in_stock` / `out_of_stock`) на основі кількості.
3. **Кошик замовлень:**
   - Додавання товарів з унікальним `cartId`.
   - Підрахунок загальної кількості та вартості замовлення в реальному часі.
   - Повне збереження та відновлення стану кошика через `localStorage`.
   - Можливість перейти до детального перегляду вибраного товару безпосередньо з вікна кошика та повернутися назад однією кнопкою.
4. **Тематичне оформлення (Theming):**
   - Перемикач світлої ☀️ та темної 🌙 теми.
   - Автоматичне визначення системної теми користувача через `window.matchMedia('(prefers-color-scheme: dark)')`.
   - Пріоритетне збереження вибору користувача в `localStorage`.
5. **Інтерактивні UI/UX фічі:**
   - **Radial Glow Border:** інтерактивне неонове підсвічування контуру карток під курсором миші.
   - **Динамічне згортання опису:** перевірка висоти блоку тексту через `useRef` (`scrollHeight > clientHeight`) та кнопка «Читати більше / Згорнути» лише там, де текст реально обрізано.

## 💻 Локальний запуск проєкту

### 1. Клонування репозиторію
```bash
git clone <URL_ВАШОГО_РЕПОЗИТОРІЮ>
cd react-store
```

### 2. Встановлення залежностей
```bash
npm install
```

### 3. Запуск локального REST API (json-server)
В окремому вікні термінала запустіть mock-сервер:
```bash
npx json-server db.json --port 3000
```
API буде доступне за адресою: `http://localhost:3000/products`

### 4. Запуск клієнтської частини (Vite Dev Server)
В основному терміналі:
```bash
npm run dev
```
Відкрийте застосунок у браузері за посиланням `http://localhost:5173`.
